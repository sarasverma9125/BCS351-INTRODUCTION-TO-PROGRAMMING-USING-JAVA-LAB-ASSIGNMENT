ASSIGNMENT 14 – CHARACTERS: COUNTING AND POSITIONS

1. Experiment Title

Characters: Counting and Positions

2. Aim

To perform character operations in Java, count vowels in a string, count the occurrences of a particular character, and display each character with its index.

3. Software / Tools Required

- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

4. Theory

A character in Java is represented by the char data type. The charAt() method is used to access a character at a particular index in a string.

Character operations help us count specific characters, identify vowels, and access the positions of characters in a string.

5. Algorithm / Procedure

Question 1: Count Vowels

1. Initialize a string with the value "programming".
2. Initialize a counter variable with 0.
3. Use a loop to access each character of the string.
4. Check whether the character is a, e, i, o or u.
5. Increase the counter whenever a vowel is found.
6. Display the total number of vowels.

Question 2: Count Occurrences of Character 'g'

1. Initialize a string with the value "programming".
2. Initialize a counter variable with 0.
3. Use a loop to access each character.
4. Check whether the current character is 'g'.
5. Increase the counter whenever 'g' is found.
6. Display the total count of 'g'.

Question 3: Print Characters with Positions

1. Initialize a string with the value "hello".
2. Use a loop starting from index 0.
3. Access each character using the charAt() method.
4. Display each character along with its index.
5. Continue until the end of the string.

6. Input

Question 1

    String: programming

Question 2

    String: programming
    Character to count: g

Question 3

    String: hello

7. Output

Question 1

    Vowels: 3

Question 2

    Count of g: 2

Question 3

    Index 0: h
    Index 1: e
    Index 2: l
    Index 3: l
    Index 4: o

8. Result

All three Java programs were successfully executed. The number of vowels and occurrences of character 'g' were counted successfully, and each character of the string was displayed along with its index.
