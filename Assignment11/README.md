ASSIGNMENT 11 – BUBBLE SORT AND SELECTION SORT

1. Experiment Title

Bubble Sort and Selection Sort

2. Aim

To sort an array of integers in ascending order using Bubble Sort and Selection Sort algorithms and count the number of swaps performed during Bubble Sort.

3. Software / Tools Required

- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

4. Theory

Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order. This process continues until the array is sorted.

Selection Sort is a sorting algorithm that repeatedly finds the smallest element from the unsorted part of the array and places it at the correct position.

Both algorithms are used to arrange elements in ascending or descending order.

5. Algorithm / Procedure

Question 1: Bubble Sort

1. Initialize an array with values 5, 1, 4, 2 and 8.
2. Compare adjacent elements.
3. Swap elements if the first element is greater than the second.
4. Repeat the process until the array is sorted.
5. Display the sorted array.

Question 2: Selection Sort

1. Initialize an array with values 64, 25, 12, 22 and 11.
2. Find the smallest element in the unsorted part of the array.
3. Swap it with the first element of the unsorted part.
4. Repeat the process until the array is sorted.
5. Display the sorted array.

Question 3: Count Swaps in Bubble Sort

1. Initialize an array with values 5, 1, 4, 2 and 8.
2. Set the swap counter to 0.
3. Compare adjacent elements.
4. Swap elements if they are in the wrong order.
5. Increase the swap counter after every swap.
6. Display the total number of swaps.

6. Input

Question 1

    Array: 5, 1, 4, 2, 8

Question 2

    Array: 64, 25, 12, 22, 11

Question 3

    Array: 5, 1, 4, 2, 8

7. Output

Question 1

    Sorted: [1, 2, 4, 5, 8]

Question 2

    Sorted: [11, 12, 22, 25, 64]

Question 3

    Swaps: 4

8. Result

All three Java programs were successfully executed. Bubble Sort and Selection Sort algorithms arranged the array elements in ascending order, and the total number of swaps performed during Bubble Sort was successfully counted.
