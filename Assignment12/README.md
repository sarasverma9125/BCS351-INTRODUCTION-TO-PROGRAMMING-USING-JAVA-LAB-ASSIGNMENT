ASSIGNMENT 12 – INSERTION SORT

1. Experiment Title

Insertion Sort

2. Aim

To sort arrays of integers in ascending order using the Insertion Sort algorithm and count the total number of shifts performed during sorting.

3. Software / Tools Required

- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

4. Theory

Insertion Sort is a simple sorting algorithm that builds the sorted array one element at a time. It takes each element and compares it with the previous elements. If the previous element is greater, it shifts that element one position to the right.

This process continues until all elements are arranged in ascending order.

5. Algorithm / Procedure

Question 1: Insertion Sort

1. Initialize an array with values 7, 3, 5 and 1.
2. Start from the second element of the array.
3. Store the current element in a variable called key.
4. Compare the key with previous elements.
5. Shift greater elements one position to the right.
6. Insert the key at its correct position.
7. Display the sorted array.

Question 2: Insertion Sort on Another Array

1. Initialize an array with values 14, 3, 9, 21 and 6.
2. Start from the second element.
3. Store the current element as key.
4. Compare it with previous elements.
5. Shift greater elements to the right.
6. Insert the key at the correct position.
7. Display the sorted array.

Question 3: Count Shifts in Insertion Sort

1. Initialize an array with values 6, 5, 4, 3, 2 and 1.
2. Set the shift counter to 0.
3. Apply the Insertion Sort algorithm.
4. Increase the shift counter whenever an element is shifted.
5. Continue until the array is sorted.
6. Display the total number of shifts.

6. Input

Question 1

    Array: 7, 3, 5, 1

Question 2

    Array: 14, 3, 9, 21, 6

Question 3

    Array: 6, 5, 4, 3, 2, 1

7. Output

Question 1

    Sorted: [1, 3, 5, 7]

Question 2

    Sorted: [3, 6, 9, 14, 21]

Question 3

    Shifts: 15

8. Result

All three Java programs were successfully executed. The Insertion Sort algorithm arranged the array elements in ascending order, and the total number of shifts performed during sorting was successfully counted.
