ASSIGNMENT 3

1. Experiment Title

Star and Number Patterns

2. Aim

To use a loop inside another loop to print stars and numbers in rows.

3. Software / Tools Required

Programming Language: Java

JDK: JDK 27

IDE / Text Editor: Visual Studio Code

Operating System: Windows

4. Theory

Nested loops are loops placed inside another loop. They are useful for printing patterns of stars and numbers. The outer loop controls the rows, while the inner loop controls the elements printed in each row.

5. Algorithm / Procedure

Question 1: Square of Stars
1. Repeat the outer loop four times.
2. Use an inner loop to print four stars in each row.
3. Move to a new line after each row.
Question 2: Right Triangle of Stars
1. Repeat the outer loop from 1 to 4.
2. Print stars equal to the current row number.
3. Move to a new line after each row.
Question 3: Number Triangle
1. Repeat the outer loop from 1 to 4.
2. Print numbers from 1 up to the current row number.
3. Print a space after each number and move to a new line.
Question 4: Upside Down Triangle of Stars
1. Start the outer loop at 4 and decrease it to 1.
2. Print stars equal to the current row number.
3. Move to a new line after each row.
